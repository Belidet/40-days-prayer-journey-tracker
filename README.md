# 40-Day Eastern Orthodox Prayer Journey

A spiritual tracking web application designed for **Belidet, Ephi, Seli, and Ermi** to track their 40-day prayer rule from **September 11, 2026** to **October 20, 2026**.

## Features
- **Authentic Orthodox Aesthetics:** Gold leaf metallic borders, dark wood tones, and candle flicker lighting effects.
- **Icon Captions:** Includes guaranteed SVG fallbacks and public domain links for Christ Pantocrator and the Vladimir Theotokos.
- **Audio & Visual Feedback:** Web Audio API synth chime and floating golden incense particles upon completing daily rules.
- **Multi-User Authentication:** Individual login sessions for each pilgrim with passwords.
- **40-Day Matrix Grid:** Interactive overview table tracking all 40 days.

## Local Image Setup
For custom offline icon imagery, place two images in the root directory:
- `christ-pantocrator.jpg`
- `theotokos-vladimir.jpg`

## Vercel Deployment Guide
1. Create a repository on [GitHub](https://github.com).
2. Push all project files (`index.html`, `style.css`, `script.js`, `vercel.json`, `README.md`, and image assets) to GitHub.
3. Go to [Vercel](https://vercel.com) and click **Import Project**.
4. Select your GitHub repository and click **Deploy**.
